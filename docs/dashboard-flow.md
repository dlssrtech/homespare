# Dashboard & Panel Flows

## Super Admin
1. Tenant setup (cities, franchises, master service taxonomy)
2. Commission blueprint & referral engine policies
3. Global analytics and anomaly alerts
4. Role/permission governance

## Admin
1. Vendor onboarding queue review
2. Booking ops monitoring and re-assignment
3. Subscription package management
4. Notification campaigns and CRM governance

## Franchise Manager
1. City-specific technician/vendor pool health
2. Revenue share and payout reconciliation
3. SLA watchlist & escalations

## Accountant
1. Daily settlement run
2. GST report validation
3. Invoice/reconciliation export
4. Refund ledger and exception handling

## Support Agent
1. Ticket triage board
2. Context view (booking timeline + payment + chat excerpts)
3. Resolution + feedback closure
