# HomeSphere UI Wireframes (Low-fidelity)

## Mobile App Navigation (Customer)

`Splash -> OTP Login -> Home -> Category -> Service Detail -> Slot Select -> Address -> Payment -> Live Tracking -> Invoice/Rating`

### Home Screen
- Top: location switcher + notification bell
- Search bar (voice icon)
- Category cards grid
- Emergency booking CTA
- Referral earnings card
- Active bookings carousel
- AI room estimator widget

### Booking Tracking Screen
- Stepper: Requested → Assigned → On the way → In progress → Completed
- Technician map tile with ETA
- Chat/Call buttons
- Upload issue photo
- Raise support ticket

### Wallet & Rewards
- Balance card
- Reward history tabs: referral / cashback / subscription
- Redeem to booking
- Withdraw (for eligible roles)

## Vendor App Navigation

`Login -> KYC -> Dashboard -> Job Queue -> Job Detail -> Route -> Start/Complete Job -> Upload Proof -> Earnings`

- Availability toggle
- Attendance punch in/out
- Route navigation deep link
- Daily payouts and referral income

## Admin Web (React)

### Primary Sidebar
- Dashboard
- Users
- Vendors & KYC
- Bookings
- Interior Projects
- Commissions
- Referrals
- Subscriptions
- CRM Tickets
- Reports
- Settings

### Dashboard Layout
- KPI cards (GMV, net revenue, active jobs, city health)
- Charts: service category, city-wise revenue, referral contribution
- Queue widgets: pending approvals, escalated tickets, failed payouts

## Theming
- Light/dark mode with consistent spacing system.
- Tokenized design system: colors, typography, radius, elevation.
