# HomeSphere Platform

HomeSphere is a scalable multi-platform ecosystem for interior design, household services, handyman operations, maintenance workflows, and referral-based earnings.

## Monorepo Layout

- `apps/mobile_flutter` – Flutter customer + multi-role app foundation
- `apps/vendor_flutter` – Flutter vendor/technician app foundation
- `apps/web_admin` – React + Vite admin/franchise/accountant/support panel foundation
- `services/api` – REST API with modular architecture, RBAC, JWT, and integrations
- `infra` – cloud deployment, containers, scaling, observability assets
- `docs` – product architecture, schema, flows, roadmap, monetization
